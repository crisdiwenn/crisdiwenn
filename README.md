# Hi, I'm Cristian Silva 👋

PhD Researcher at **Chalmers University of Technology**, Gothenburg, Sweden.  
I study microbial communities in wastewater treatment systems using metagenomics and bioinformatics.

---

## Research

- 🦠 Methanotrophic bacteria, anammox, and microbial ecology in engineered systems
- 🧬 Metagenome-assembled genomes (MAGs), functional annotation, and taxonomic profiling
- 💻 HPC workflows on SLURM clusters using Nextflow, bash, and Python
- 🔬 Investigating the methane paradox in partial nitrification-anammox reactors
